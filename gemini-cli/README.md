# Home Assistant Add-On: Gemini CLI UI

![Supports aarch64 Architecture][aarch64-shield] ![Supports amd64 Architecture][amd64-shield]

The add-on provides [Gemini CLI UI](https://github.com/cruzyjapan/Gemini-CLI-UI) running within Home Assistant instance.
It's based on [Gemini CLI in Docker](https://hub.docker.com/r/tgagor/gemini-cli)
